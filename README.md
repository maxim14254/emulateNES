# Очередной эмулятор NES/Dendy/Famicom
### Каждый уважающий себя  ~~задрот~~ энтузиаст должен сделать очередной никому не нужный эмулятор NES
### В эмуляторе реализованы сохранения\загрузка и назначение клавиш управления. Так же есть режим debug в котором отображаются процессорные инструкции, палита, тайлы, спрайты, регистры cpu(ppu) 
### Реализация
- С++17
- Qt 5.15
### Сборка 
#### Linux
```bash
sudo apt update
sudo apt install qtbase5-dev qtmultimedia5-dev libqt5multimedia5-plugins libglu1-mesa-dev
```
#### macOS
```bash
brew install qt@5
```
#### Для Windows есть готовый релиз
